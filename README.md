# opus55video — code-driven explainer video studio

The LLM plays director, writer and motion designer. Every frame is **generated by code**: a storyboard JSON drives procedural canvas scenes. No video editor or templates are involved. Because every pixel is a pure function of time `t`, frames can be rendered in any order by any number of workers. That is what makes GPU/CPU-parallel rendering possible.

```
opus55video/
├─ engine/                    # project-agnostic engine
│  ├─ tts.py                  # script.json → build/voice/*.mp3 + voice.json (parallel, hash-cached)
│  ├─ timeline.mjs            # script + voice durations → absolute scene/line timing (shared A/V clock)
│  ├─ audio.mjs               # voice placement + procedural score + SFX + ducking → build/mix.wav (CPU)
│  ├─ render.mjs              # N headless Chrome (GPU canvas) → N NVENC encoders → concat → mux
│  ├─ build.mjs               # one-command pipeline (tts → render ∥ audio)
│  └─ runtime/
│     ├─ core.js              # deterministic compositor: easing, typography, glass, rings, bokeh, grain, HUD, subtitles
│     └─ player.html
├─ projects/<name>/           # one folder per video
│  ├─ script.json             # storyboard: scenes, narration lines, params, assets
│  ├─ scenes.js               # this video's procedural scene library
│  ├─ assets/images/          # source stills
│  └─ build/                  # generated: voice, img (upscaled), timeline.json, chunks, mix.wav, stills
└─ output/<name>.mp4          # final deliverable
```

## Usage
```powershell
npm run build -- projects/50mm-portrait                  # full pipeline
node engine/render.mjs projects/50mm-portrait --stills 3,20,65   # QA stills
node engine/render.mjs projects/50mm-portrait --from 40 --to 70  # partial render
node engine/timeline.mjs projects/50mm-portrait          # print scene timing
```

## Parallelism
| Stage | Resource | Strategy |
|---|---|---|
| TTS | network | Azure Speech REST (`eastasia`, `zh-CN-XiaoxiaoNeural` `gentle`), content-hash cache |
| Asset prep | CPU | concurrent ffmpeg lanczos upscale |
| Frames | GPU (ANGLE/D3D11 canvas) + 1 CPU core per worker | N Chrome workers, contiguous frame ranges |
| Encode | NVENC | one h264_nvenc stream per worker, lossless concat |
| Audio | CPU | synthesized concurrently with the video render |

## TTS Configuration (Azure Cognitive Services Speech)
- **Channel**: `F0 · cdh-speech-eastasia-f0` (`SPEECH_REGION=eastasia`)
- **REST Endpoint**: `https://eastasia.tts.speech.microsoft.com/cognitiveservices/v1`
- **Default Voice**: `zh-CN-XiaoxiaoNeural`, `style="gentle"`, `rate="0.95"`, `pitch="0%"`, `format="audio-24khz-48kbitrate-mono-mp3"`
- **Scene / Line Overrides**: In `script.json`, both `scenes[i]` and individual `lines[j]` objects can override `voice` (or `name`), `style` (e.g. `gentle`, `chat`, `friendly`, `affectionate`, `cheerful`, `calm`, `lyrical`, `serious`, `newscast`, `whisper`), `styledegree`, `role`, `rate`, and `pitch`.
